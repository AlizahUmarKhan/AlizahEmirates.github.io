# Alizah Khan — Portfolio 2026

A plain HTML/CSS/JavaScript interactive portfolio inspired by a luxury passport and boarding-pass journey.

## Run it

Open `index.html` in a modern browser.

## Files

- `index.html` — page structure and portfolio content containers
- `style.css` — all visual styling and animation
- `script.js` — screen transitions and editable CV data
- `assets/peacock-gold-embossed.png` — cleaned/recolored version of the supplied peacock artwork, with a gold foil/emboss treatment
- `assets/peacock.png` — original supplied artwork

## Editing your CV

Open `script.js` and edit the `CV_DATA` object near the top. You can change the name, title, profile, skills, experience, projects, email, and website without changing the interaction code.

## Current interaction

1. Boarding screen appears on load.
2. It automatically moves to the passport after about 2.6 seconds.
3. Click the passport to open the portfolio passport.
4. The opened portfolio passport keeps the airline/passport layout but intentionally has no peacock on that second page.
5. Click again to reveal the live boarding-pass CV.

The passport emblem uses the original peacock silhouette from the supplied artwork, converted to a smaller gold embossed treatment and placed inside a restrained oval passport stamp.
